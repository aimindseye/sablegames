# Sable Games 1.0.0

The first full release: sixteen keyboard-first games, each its own app, for BlackBerry-style Android phones such as the Zinwa Q25 and the Unihertz Titan 2. They play from the keys and the trackpad, and also by touch.

## The apps

| App | What it is |
| --- | --- |
| Bitter Melons (new) | A slingshot physics game. Fling angry melons and topple the AI Slop across World 1's nine levels |
| Sable Games Console | Runs games written as small Lua scripts. Ships with eight tilt games, and you can add your own |
| Sable Card Games | Ten Indian card games: Teen Patti (practice chips only), Indian Rummy, Mendicot, Callbreak, Judgement, 2-3-5, Bluff, Donkey, Gulam Choor and Filmi Rummy |

## What's new since the 0.1 builds

### Bitter Melons
- **World 1, nine levels:** First Prompt to The Vibe-Coder's Shed. Structures are built from glass, wood and stone, guarded by Slop Apps, AI Bots and gold Premium Ad-Slop.
- **Real physics (JBox2D):** blocks topple, Overheated Batteries explode and set each other off, and breaking the gold Ad-Slop doubles block points for a few seconds.
- **Seed Burst:** press Space in the air to split the melon into three fast seeds.
- **Target window:** while you aim, a live view of the structure sits in the corner, with its distance and a red ring where the shot will land. Each level opens with a pan over the structure.
- **Result panel:** at the end of a level, shows the seeds won (up to three) and the score, with Next level or Try again. Clearing a level opens the next, and progress is kept.
- **Hand-painted art:** the melons get angrier with each shot, enemies show damage, and blocks crack in four stages.
- **Fills the screen:** the board uses the whole screen on the Q25 and the Titan 2.

### Other games
- **Bricks:** the ball is about 40% slower at every difficulty.

### Every app
- **Fits the phone:** each game reads which phone it runs on and fits its keys to it. The Q25 uses its trackpad and arrows; the Titan 2, which has no arrows, uses I J K L.
- **Shared frame:** a top bar with Pause, New and Menu, how-to-play pages, and key settings.

## Install

Download the APKs you want below and open each one on the phone, or run `adb install sable-<game>-1.0.0.apk` from a computer. `SHA256SUMS.txt` lists every file's SHA-256, so you can check a download with `sha256sum -c SHA256SUMS.txt`.

- Android 11 or later.
- No permissions: no internet, no storage and no location. The only exception is the app-private one AndroidX adds for its own receivers.
- Everything works offline, with no ads and no accounts.
- Every APK is signed with the same key as TenSeven Launcher. Its certificate SHA-256 is `9b2047390e5aa77537b8e8875cdfd3c2c72d0a0715e172a7f77457fc4300f292`.

If you installed a 0.1 build signed with the same key, 1.0.0 installs over it and keeps your scores and progress.

## Known limits

- Bitter Melons has World 1 only, and no sound yet.
- Lua console games run sandboxed: no files, no network, and limits on time and memory.
- The planned installer that sets up several games in one go is not part of 1.0.
