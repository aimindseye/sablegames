# Phone checks

Checks run by hand on a phone, carried over from SableOS's qualification list. Status values: `PASS`, `FAIL`, `BLOCKED`, `NOT_RUN`. A check passes on the stock firmware of each phone it names; on SableOS the same checks are kept in SableOS's own `docs/QUALIFICATION.md`.
